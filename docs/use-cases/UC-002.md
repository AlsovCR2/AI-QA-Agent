# UC-002 - El agente explora la estructura del proyecto

| Campo | Valor |
|-------|-------|
| **ID** | UC-002 |
| **Título** | El agente explora la estructura del proyecto |
| **Prioridad** | P1 |
| **Estado** | Aprobado |
| **Versión** | 1.0 |
| **Fecha** | 2026-08-11 |

## Actores

- **Usuario**: profesional de QA que desea comprender la organización de un
  proyecto de software.

## Descripción

El usuario solicita comprender la estructura del proyecto (archivos,
directorios, componentes) y el agente la explora presentando información
estructural real obtenida mediante su herramienta de exploración, evitando al
usuario recorrer manualmente el proyecto.

La herramienta de exploración reporta únicamente información real de la
estructura existente; nunca inventa contenido.

## Disparador

El usuario solicita comprender la estructura del proyecto.

## Precondiciones

1. El usuario tiene acceso explícito y autorizado al proyecto.
2. El proyecto contiene archivos y directorios.
3. La herramienta de exploración está disponible.

## Flujo Principal

1. El usuario solicita comprender la estructura del proyecto.
2. El agente identifica la herramienta de exploración como pertinente.
3. El agente ejecuta la herramienta de exploración sobre el proyecto.
4. La herramienta reporta la información estructural real del proyecto.
5. El agente valida el resultado obtenido.
6. El agente presenta la información estructural real localizada.
7. El agente muestra el historial visible de la exploración ejecutada y su
   resultado.
8. El caso de uso termina.

## Flujo Alternativo 2a - Ruta inexistente o no autorizada

1. El usuario solicita explorar una ruta que no existe o para la cual no hay
   autorización.
2. La herramienta no puede acceder a dicha ruta.
3. El agente informa que no puede acceder a la ruta.
4. El agente no inventa contenido ni estructura.
5. El caso de uso termina.

## Postcondiciones

1. La respuesta incluye los elementos estructurales reales localizados.
2. Si se intentó acceder a una ruta inexistente o no autorizada, el agente
   informó la imposibilidad sin inventar contenido.
3. El historial visible registra la exploración y su resultado.

Los casos de uso UC-003, UC-004 y UC-005 dependen de la capacidad de exploración
aquí definida (FR-006) como base para localizar archivos y ejecutar las demás
tareas de análisis y validación.
