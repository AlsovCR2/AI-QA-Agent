# UC-004 - El agente revisa y busca patrones en el código

| Campo | Valor |
|-------|-------|
| **ID** | UC-004 |
| **Título** | El agente revisa y busca patrones en el código |
| **Prioridad** | P2 |
| **Estado** | Aprobado |
| **Versión** | 1.0 |
| **Fecha** | 2026-08-11 |

## Actores

- **Usuario**: profesional de QA que desea revisar partes del código y buscar
  patrones específicos.

## Descripción

El usuario solicita revisar partes del código o buscar un patrón específico, y
el agente ejecuta la búsqueda correspondiente, presentando los resultados reales
en contexto. El agente cita el código real del proyecto tal como existe, sin
alterarlo.

## Disparador

El usuario solicita revisar o buscar un patrón en el código del proyecto.

## Precondiciones

1. El usuario tiene acceso explícito y autorizado al proyecto.
2. La herramienta de revisión/búsqueda de patrones está disponible.
3. El usuario especifica el patrón o las partes a revisar.

## Flujo Principal

1. El usuario solicita revisar o buscar un patrón en el código.
2. El agente identifica la herramienta de revisión/búsqueda como pertinente.
3. El agente ejecuta la búsqueda correspondiente sobre el proyecto.
4. La herramienta devuelve los resultados reales con su contexto.
5. El agente valida el resultado obtenido.
6. El agente presenta las ocurrencias reales en contexto, citando el código tal
   como existe sin alterarlo.
7. El agente muestra el historial visible de la revisión ejecutada y su
   resultado.
8. El caso de uso termina.

## Flujo Alternativo 1a - No se encuentran ocurrencias del patrón

1. La búsqueda de patrones no encuentra ocurrencias.
2. El agente informa la ausencia de resultados.
3. El agente **no** fabrica contenido ni concordancias ficticias.
4. El caso de uso termina.

## Postcondiciones

1. El contenido de código presentado coincide con el proyecto real y no está
   alterado.
2. Las ocurrencias del patrón se muestran con su contexto real.
3. El historial visible registra la revisión y su resultado.

## Trazabilidad

- **User Story**: US-4 (El agente revisa y busca patrones en el código).
- **Requisitos funcionales**: FR-009, FR-010, FR-011.
- **Principios de la constitución**: VII (Validación y contratos), VIII
  (Observabilidad y trazabilidad), IX (Manejo seguro de errores), VI
  (Determinismo).
- **Criterios de éxito**: SC-002, SC-003, SC-006.

## Notas

Revisar y buscar patrones habilita el análisis de errores (UC-005) y la
generación de casos de prueba. El contenido de código debe presentarse siempre
fiel al proyecto real.
