# UC-003 - El agente localiza archivos y componentes

| Campo | Valor |
|-------|-------|
| **ID** | UC-003 |
| **Título** | El agente localiza archivos y componentes |
| **Prioridad** | P2 |
| **Estado** | Aprobado |
| **Versión** | 1.0 |
| **Fecha** | 2026-08-11 |

## Actores

- **Usuario**: profesional de QA que busca localizar archivos, clases, funciones
  o componentes específicos.

## Descripción

El usuario solicita localizar un archivo, clase, función o componente dentro del
proyecto y el agente realiza una búsqueda, devolviendo únicamente las
coincidencias reales encontradas. Si no se encuentra ninguna coincidencia, el
agente informa la ausencia de resultados sin fabricar concordancias ficticias.

## Disparador

El usuario solicita localizar un archivo, clase, función o componente.

## Precondiciones

1. El usuario tiene acceso explícito y autorizado al proyecto.
2. La herramienta de búsqueda/localización está disponible.
3. El usuario especifica el elemento a localizar.

## Flujo Principal

1. El usuario solicita localizar un archivo, clase, función o componente.
2. El agente identifica la herramienta de localización como pertinente.
3. El agente ejecuta la búsqueda sobre el proyecto.
4. La herramienta devuelve las coincidencias reales encontradas.
5. El agente valida el resultado obtenido.
6. El agente reporta las coincidencias reales pertinentes.
7. El agente muestra el historial visible de la búsqueda ejecutada y su
   resultado.
8. El caso de uso termina.

## Flujo de Excepción 4a - Sin coincidencias

1. La herramienta de localización no encuentra coincidencias.
2. El agente valida que el resultado está vacío.
3. El agente informa la ausencia de resultados.
4. El agente **no** fabrica concordancias ficticias.
5. El caso de uso termina.

## Postcondiciones

1. Se reportan únicamente las coincidencias y datos reales existentes en el
   proyecto.
2. Si no había coincidencias, se informó la ausencia sin inventar resultados.
3. El historial visible registra la búsqueda y su resultado.

## Trazabilidad

- **User Story**: US-3 (El agente localiza archivos y componentes).
- **Requisitos funcionales**: FR-007, FR-008.
- **Principios de la constitución**: VII (Validación y contratos), VIII

## Notas

La localización rápida es central para el análisis de errores y la revisión de
código. La regla de honestidad de UC-007 aplica directamente en este caso de
uso cuando no hay coincidencias.
